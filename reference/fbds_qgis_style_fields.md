# Campos com estilo do QGIS disponivel

Campos com estilo do QGIS disponivel

## Usage

``` r
fbds_qgis_style_fields()
```

## Value

Vetor de nomes de campo (ex. `"CLASSE_USO"`), um por arquivo `.qml`
empacotado em `inst/qgis/`.

## Examples

``` r
fbds_qgis_style_fields()
#> [1] "CLASSE_USO"             "HIDRO"                  "MAPBIOMAS"             
#> [4] "NATUREZA"               "PLANAFLOR-RECOMPOSICAO" "RIO"                   
```
