# geofbds: Download and Read Municipal Data from Geo FBDS

Discovers, downloads, and reads geospatial land-use, hydrography, and
permanent preservation area (APP) data published by the Fundacao
Brasileira para o Desenvolvimento Sustentavel (FBDS) for Brazilian
municipalities. Provides a resolver from IBGE geocode, municipality
name, or state (UF) to a frozen internal catalog, parallel resumable
downloads via curl, and an auditable manifest of every transfer.
